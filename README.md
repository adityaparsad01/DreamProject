# Java + DSA Job Roadmap 2026

A job-oriented roadmap for learning **Java, Data Structures & Algorithms, SQL, and Spring Boot**, with a practical software-development focus.

## Goal

Build strong DSA fundamentals in Java, then move into backend development and job preparation.

## 6-Month Roadmap

### Month 1 — Java + DSA Fundamentals
- Java syntax, variables, loops, methods
- OOP fundamentals
- Time and space complexity
- Arrays and strings
- Recursion basics
- Sorting and searching

### Month 2 — Core DSA
- Binary search
- Linked lists
- Stack and queue
- Hashing
- Two pointers
- Sliding window

### Month 3 — Advanced DSA
- Trees and BST
- Heap / Priority Queue
- Greedy algorithms
- Backtracking
- Graph fundamentals

### Month 4 — Advanced Problem Solving
- Graph algorithms
- Dynamic programming
- Tries
- Bit manipulation
- Advanced recursion

### Month 5 — Backend Development
- SQL
- JDBC
- Spring Boot
- REST APIs
- JPA / Hibernate
- Authentication
- Git and GitHub

### Month 6 — Job Preparation
- 2 strong Java + Spring Boot projects
- DSA revision
- LeetCode practice
- SQL interview questions
- Java and OOP interview questions
- System design basics
- Resume and GitHub preparation
- Mock interviews

## Daily Target

**2.5–3 hours/day**

1. 60 min — DSA concept + Java implementation
2. 60 min — 2–3 coding problems
3. 45 min — Java / Spring Boot
4. 15 min — Revision and notes

## DSA Practice

The problem sequence will follow the **Striver A2Z DSA Sheet**, implemented in Java.
